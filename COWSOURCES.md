# Cow artwork sources

The cow templates included in this repository are intentionally small,
freehand ASCII templates maintained with the project under the same
GPL-3.0-or-later terms as the C source.

Research notes:

- The actively maintained cowsay project publishes its distribution as
  GPL-licensed free software and documents the cow-file licensing status.
- Distribution metadata such as Fedora and the FSF Free Software Directory
  also describe cowsay as free software.

These notes are here to document why the project uses the conventional
`.cow` template layout while keeping the bundled templates license-clean.
